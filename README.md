# Blockchain-Based Secure Document Sharing Platform

> A decentralized, cryptographically secure document sharing platform built
> using AES-256 Encryption, IPFS, Ethereum Smart Contracts, and MongoDB.

## Tech Stack

| Layer       | Technology                               |
|-------------|------------------------------------------|
| Frontend    | React.js (Vite), Tailwind CSS, Ethers.js |
| Backend     | Node.js, Express.js, JWT, Multer         |
| Database    | MongoDB Atlas                            |
| Blockchain  | Solidity, Hardhat, Ethereum Sepolia      |
| Storage     | IPFS via Pinata                          |
| Encryption  | AES-256, SHA-256                         |
